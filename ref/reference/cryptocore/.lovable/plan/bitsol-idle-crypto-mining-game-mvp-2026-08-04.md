# BITSOL — Idle Crypto Mining Game (MVP)

A fully client-side idle mining game: mine BITSOL with equipment-driven hash rate, bank it in a vault, claim it, raid rival players, open chests for random NFT-style gear, and spend BITSOL on permanent stat upgrades. No backend — all state lives in Zustand with localStorage persistence.

## Stack notes (two deviations from the request)

- Routing uses **TanStack Router** (file-based, already in this project) instead of React Router. Same pages, same URLs — React Router isn't supported here.
- Fake raid opponents are generated by a small local name/avatar generator instead of adding Faker as a dependency (keeps the bundle lean; output is equivalent).
- Everything else is as specified: React 19 + TypeScript + Vite, Tailwind v4, shadcn/ui, Zustand + persist, Framer Motion, Lucide.

## Pages

| Route | Content |

| `/` Dashboard | Vault card (fills live), hash rate, mining/sec, BITSOL wallet, mining progress bar, claim button, recent activity feed, top stats, quick nav |
| `/rig` Mining Rig | 6 equipment slots, inventory grid with filter/sort/search, equip/unequip, power score, live total stats |
| `/stats` Stats | 6 permanent stats with upgrade cards, cost = level², live totals (base + equipment) |
| `/raid` Raid | 20 generated rivals, raid resolution with animation and result modal |
| `/chests` Chests | Bronze/Silver/Gold/Diamond/Bitcoin, opening animation, reward modal |
| `/marketplace` | UI only, buy disabled |
| `/profile` | Wallet, vault, equipment count, best hash rate, raids, wins, total claimed |
| `/settings` | Notifications toggle, animation toggle, reset save (with confirm) |

Shared shell: sidebar nav + header (wallet + vault readout) + footer, in the root layout. Responsive desktop → tablet → mobile (sidebar collapses to a sheet).

## Game rules being implemented

- **Mining:** ticks every second. `mined/sec = totalHashRate × 1` (multiplier fixed at 1 for MVP). Offline time since last visit is credited on load, capped by vault capacity.
- **Vault:** `capacity = 100 + vaultLevel × 20`. Mining halts at full and fires a "Vault Full" notification.
- **Claim:** moves the whole vault to wallet, vault → 0, counts toward total claimed.
- **Stats:** HashRate, HackPower, Security, Luck, Firewall, Exploit. Upgrade cost `= level²`, paid from wallet.
- **Equipment:** 6 slots (ASIC Miner, Motherboard, Power Supply, Cooling System, Network Module, Firmware Chip), one item per slot. Stats roll from the same shared pool for every slot, no duplicate stat on one item.
- **Rarity → stat count:** Common 1, Uncommon 2, Rare 3, Epic 4 or 5 (50/50), Legendary 6, Mythic 6 (higher rolls).
- **Roll ranges:** Common 1–10, Uncommon 2–20, Rare 3–30, Epic 4–50, Legendary 6–60, Mythic 8–80.
- **Power score:** sum of an item's stat values; used for inventory sorting.
- **Total stats:** base (upgraded) + sum of equipped item stats, live.
- **Chest prices:** 100 / 300 / 750 / 2000 / 5000 BITSOL, each with its own rarity odds table; reward is a fully random item added to inventory.
- **Raid:** `successChance = clamp(50 + (myHackPower - enemySecurity) / 2, 10, 90)`. Then a firewall check: roll 1–100, if `roll <= enemyFirewall` the raid fails. On success, steal percentage rolls between `Exploit` and 100 (as a percent), stolen = `enemyVault × steal%`, credited to wallet; the rival's security/vault are reduced afterward. Wins/attempts tracked.

## Technical shape

```text
src/game/          pure logic: mining, vault, raid, chest, equipment
                   generation, stat totals, score, upgrade cost
src/stores/        player, equipment, chest, raid, settings, notification
                   (each zustand + persist, versioned)
src/features/*/    per-feature components (dashboard, rig, chests, raid…)
src/components/    StatCard, EquipmentCard, EquipmentSlot, EquipmentGrid,
                   MiningProgress, VaultCard, ChestCard, ChestModal,
                   RaidCard, UpgradeCard, Navbar/Sidebar/Header/Footer,
                   NotificationToast
src/types/, src/constants/, src/hooks/  (incl. useMiningTick)
src/routes/        TanStack route files, one per page
```

- Zero business logic in components — components read stores and call `src/game` helpers, so the persistence layer can be swapped for a server later without touching rules.
- Design tokens added to `src/styles.css` in oklch: background `#0B1220`, card `#111827`, primary Bitcoin orange `#F7931A`, accent Solana purple `#9945FF`, success `#22C55E`, danger `#EF4444`. Dark-only, rounded cards, soft shadows. No hardcoded color classes.
- Framer Motion on claim, chest open, equip, stat increase, vault/number counters, card hover. Notifications via sonner, honoring the settings toggle.
- Equipment art: generated rarity-tinted rig icons/images stored as assets, reused per slot type.
- Each route gets its own SEO head() metadata.

## Out of scope for the MVP

Real multiplayer, marketplace purchases, selling items, forging, quests, wallet connection.
